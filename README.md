# PreCon
MtG PreCon Escalation League Tracker

Summary of the v0.7 User's Guide
Section 	Key Features Covered
1. Getting Started 	Single-file zero-dependency setup, tablet & smartphone home-screen operation, local storage engine.
2. Roster Management 	Interactive player roster tag pills (✓ / +), quick-add search with autocomplete, full attendance list editor.
3. Pod Generator 	Optimal 3- and 4-player pod partitioning, Game 1 random seating, Game 2 seeded winners pod pairing.
4. Active Match Lobbies 	Table self-reporting, smart deck & commander pre-fills, in-lobby mid-round player additions/removals, 1-click verification toasts.
5. Ban List Model 	The 15 fully banned precons vs. conditional/alternate commander required decks (Breed Lethality, Timeless Wisdom, Elven Empire).
6. Precon Catalog 	Verified alternate commanders (Wildsear, Chatterfang, Kilo, Apogee Mind, etc.), sortable column headers, full text search.
7. League Scoring 	4-3-2-1 placement point progression, tie-breaking formulas, and live leaderboard calculations.
8. Admin & Backups 	JSON export/import for device syncing, match history corrections, season reset tools.
